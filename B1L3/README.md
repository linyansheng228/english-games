# Where Are the Cats?

康軒第一冊第三課（B1L3），七年級位置介系詞練習。

## 開啟方式

在 Windows 檔案總管中雙擊 `index.html`，以 Chrome 或 Edge 開啟。
不需安裝、不需伺服器、不需網路。移動或分享遊戲時，請保留整個 B1L3 資料夾。
教室投影可按 F11 全螢幕，再按一次退出。
首次開啟時，房間圖片會刷淡，中央顯示「START」。開始前貓咪選取、拖曳、下一題與重播都停用；按下 START 才恢復圖片並開放操作與朗讀。
每題會以自然美式英語唸兩遍，兩遍之間間隔 1 秒；可按「再聽一次」重播。
朗讀使用本機 MP3，不依賴裝置安裝的語音或網路。答對播放清楚的單聲貓叫錄音（約 1.24 秒），答錯播放合成的不高興貓叫；按 Finish 後播放掌聲夾雜歡呼聲。
按 START 後會播放低音量原創背景音樂，可按「背景音樂：開／關」切換。朗讀與音效期間，音樂會自動降低音量，結束後恢復；切換題目不會重新播放音樂。
隨時按「重新開始」，會清除所有答題進度與房間內的貓咪，取消拖曳和等待中的朗讀，停止朗讀、音效與音樂，回到刷淡圖片的 START 畫面。音樂開關偏好會保留。Play Again 也使用相同重設流程。
六題介系詞 in、between、on、under、in front of、next to 都會以紅色粗體及底線強調，原句維持完整。
每輪六題隨機排列，各出現一次、不重複。按「重新開始」或 Play Again 會重新洗牌；朗讀音檔會跟隨當前句子，Finish 只在本輪第六題答對後出現。
答題計時器顯示「本題」與「總計」時間。START 開始計時，答錯繼續累計，本題全數答對後暫停；按 Next 才開始下一題。等待 Next 或 Finish 的時間不列入總計，朗讀期間則照常計時。過關畫面會顯示總答題時間；重新開始與 Play Again 都會歸零。

## 操作與測試

1. 每題先把貓咪拖到牆上，應出現 **Try again!**，貓咪回到下方選取區，Next 保持停用。
2. 依當前隨機出現的句子拖到正確位置，應出現 **Correct!**，並自動對齊位置：
   - Lucy：左邊箱子內，已放寬至整個箱子附近的落點；角色稍放大並往箱內下移，答對後箱子前緣應遮住身體下方。
   - Billy：箱子與椅子之間的地板，判定已向左右及下方放寬；答對後 Billy 比箱子高。
   - Milo：桌面上；答對後靠在書本上，往椅子上的毛線方向伸出前腳。
   - Tommy：桌子下、兩隻前桌腳之間。
   - Sammy 與 Maggie：電視前方的地板，判定仍保留右側大範圍；答對後都在電視底座正前方，Maggie 往左避開電源線並略擋住 Sammy，不受放置先後順序影響。只放對一隻時不能進下一題。
   - Puffy：僅限機器狗左側或右側；不論從哪側答對，都固定放在機器狗右方。Puffy 稍放大並向左靠，只有左側少部分被機器狗遮住，整隻仍在圖片內。放在機器狗正前方或身上都算錯。
3. 每題答對後按 Next；最後一題按 Finish，應出現過關畫面。
4. 按 Play Again，應回到第一題 START 畫面，房間內七隻貓咪全部清除。遊戲進行中也可按「重新開始」。
5. 縮放視窗後再試一次。位置以房間的相對座標計算。
6. 手機或平板可用手指拖曳，也可以先點貓咪，再點房間中的位置。
7. 聽完每題兩遍，確認兩遍間停頓 1 秒；切換題目或重播時，前一段朗讀應停止。確認答對和答錯的聲音不同。
8. 開關背景音樂，確認不影響朗讀與答題音效；朗讀中重新開始，應取消舊題第二遍朗讀並停止背景音樂。
9. 檢查 START 前計時為 00:00；開始後遞增，答對後暫停，Next 後本題歸零、總計延續。雙貓題只放對一隻時仍繼續計時，過關時顯示總時間，重新開始則全部歸零。

拖曳時以手指或滑鼠指標所在處作為貓咪腳底的落點。只有本題指定的貓咪會出現在選取區；答對後會保留在房間中。
鍵盤操作：Tab 選取貓咪、Enter 選取，再用方向鍵移動落點（Shift 加速），Enter 放下，Esc 取消。

- 桌面 1366px 滑鼠與 390px 手機觸控模擬：七隻貓咪拖曳、六題正誤回饋、Sammy 與 Maggie 雙貓限制、過關與重新開始。
- 調整至 768px 後點選放置；圖片載入、頁面無水平溢出、沒有 JavaScript 錯誤。
- 人工檢視去背預覽與完成畫面。
- Lucy 較前一版放大約 11% 並往箱內下移；Billy 已放大到比箱子高，Milo、Tommy 保留放大的尺寸，Puffy 調整到能完整站在機器狗右側的大小。
- 桌面及觸控模擬檢查電視前方擴大範圍，以及 Puffy 左邊／右邊接受、正前方／狗身上拒絕的判定。

- Lucy 與 Billy 新擴充範圍、遊戲中重新開始與返回 START，均納入滑鼠和手機觸控模擬測試。
- `tools/test-audio.cjs` 檢查 10 個使用中的本機音檔能解碼、實際播放兩遍與 1 秒間隔、切換取消舊朗讀、三個音效播放完成，以及背景音樂循環、開關、音量降低與重設後停止。

## 音效授權

目前答對貓叫使用 Sadiquecat 的 CC0 錄音，掌聲與歡呼使用 Zeraora 的 CC0 錄音，背景音樂為本遊戲原創。來源與修改方式見 `assets/audio/CREDITS.md`，遊戲頁面也有「音效來源」可展開查看。專案中保留的舊版素材有各自授權，分享專案時請一併保留授權檔。

開發檢查腳本為 `tools/test-game.cjs`（使用 Codex 隨附的 Playwright 與本機 Chrome），一般遊玩不需這些工具。實體手機觸控仍建議依上列步驟確認手感。
